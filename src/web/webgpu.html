OpenAI Privacy Filter WebGPU

Runs PII detection on your device with WebGPU when supported and capable, and automatically falls back to the server-side openai/privacy-filter model otherwise. On-device detection combines an in-browser NER model (names & locations) with local pattern matching (email, phone, URL, date, account numbers, secrets).

How on-device vs server processing works
  • Auto: uses WebGPU on-device if your browser supports it and the device looks capable; otherwise it automatically uses the server model.
  • On-device (WebGPU): forces in-browser inference — text never leaves your machine. If on-device processing isn't available or fails, your text is not sent anywhere; you're asked first and can explicitly choose to use the server.
  • Server: always uses the higher-fidelity openai/privacy-filter model on the backend.
  • On-device detection is an approximation (browser NER + regex) and may differ from the server model's results.
  • Automatic, silent server fallback happens only in Auto mode.
